# Sistema de Control de Autobuses

Aplicación de escritorio desarrollada en C# para la gestión y control de autobuses, choferes, rutas y asignaciones. El sistema permite administrar la información de forma organizada mediante una arquitectura multicapa.

---

## Tecnologías

- C#
- .NET Framework
- Windows Forms
- Oracle Database
- PL/SQL
- ADO.NET
- Visual Studio

---

## Arquitectura

El proyecto está organizado mediante una arquitectura multicapa, separando las responsabilidades principales de la aplicación:

- **Capa de Presentación:** Interfaz gráfica y formularios del sistema.
- **Capa de Negocio:** Lógica y validaciones de la aplicación.
- **Capa de Datos:** Conexión con Oracle y acceso a los datos mediante repositorios.
- **Capa de Entidades:** Clases que representan la información utilizada por el sistema.

---

## Funcionalidades

- Inicio de sesión de usuarios.
- Gestión de autobuses.
- Gestión de choferes.
- Gestión de rutas.
- Registro y control de asignaciones.
- Operaciones de insertar, modificar, eliminar y consultar registros.
- Validación de datos desde la capa de negocio.
- Uso de procedimientos almacenados en Oracle.
- Panel principal con información general del sistema.
